# シリーズ構成 v2（制作方針）

## 第1話：にじのくにの なかまたち
目標尺：2〜3分（予算検証後に確定）
テーマ：世界観と仲間の紹介、虹の消失、冒険の出発

1. 0:00–0:25 いつも虹が出ている素敵な世界。ゆったりと世界を見せる。
2. 0:25–1:10 うさぎ、くま、きつね、りす等が性格の伝わる動きとともに登場。人数・名前はキャラデザイン確定時に決める。
3. 1:10–1:35 虹の近くでみんなで遊ぶ。オリジナルのテーマ音楽。
4. 1:35–1:50 突然、虹が消える。怖すぎない驚きの演出。
5. 1:50–2:20 みんなで会議。虹を探すことを決める。
6. 2:20–2:40 うさぎが冒険に出る。次回への引き。

時間は仮。各シーンは静止画パン／繰り返しアニメ／重要シーンの動画生成を混ぜて費用を抑える。
既存Kling 5秒素材は外観・画質の参考。利用規約・商用利用条件が確認できるまで公開素材に含めない。

## 第2話：はじめての ぼうけん
色を探す旅の始まり。赤い花・黄色い蝶・青い川などで色を学ぶ。
第1話で色の学習を詰め込まず、世界とキャラへの愛着を優先。

## 品質・制作ゲート
- 主要キャラのモデルシートと一貫した衣装・色・体格
- 第1話のナレーション／オリジナルBGM／効果音
- 30秒のパイロットで動きと視聴体験を先に検証
- 2〜3分版の素材生成見積もりと予算承認
- 日英音声差し替え
- 子ども向け設定、権利、公開前チェック
